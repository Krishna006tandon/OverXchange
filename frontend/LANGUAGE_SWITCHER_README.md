# भाषा स्विचर (Language Switcher) - OverXchange

## 📋 विवरण (Description)

OverXchange प्रोजेक्ट में एक डायनामिक भाषा स्विचर सिस्टम जोड़ा गया है जो उपयोगकर्ताओं को हिंदी और अंग्रेज़ी के बीच स्विच करने की अनुमति देता है।

## ✨ मुख्य विशेषताएं (Key Features)

- 🌐 **रीयल-टाइम भाषा स्विचिंग**: पेज को रीलोड किए बिना तुरंत भाषा बदल जाती है
- 💾 **उपयोगकर्ता पसंद सहेजना**: भाषा की पसंद localStorage में सहेजी जाती है
- 🎨 **सुंदर UI**: आकर्षक और उपयोगकर्ता-अनुकूल इंटरफेस
- 📱 **रेस्पॉन्सिव डिज़ाइन**: मोबाइल और डेस्कटॉप दोनों पर अच्छी तरह काम करता है
- 🔄 **सभी पेजों पर उपलब्ध**: पूरे प्रोजेक्ट में एकीकृत

## 🚀 उपयोग (Usage)

### उपयोगकर्ता के लिए:
1. किसी भी पेज पर जाएं
2. ऊपर दाईं तरफ भाषा स्विचर बटन देखें
3. हिंदी (🇮🇳) या अंग्रेज़ी (🇺🇸) पर क्लिक करें
4. पेज तुरंत नई भाषा में बदल जाएगा

### डेवलपर के लिए:

#### 1. भाषा स्विचर जोड़ना:
```html
<script src="language-switcher.js"></script>
```

#### 2. अनुवाद योग्य तत्व बनाना:
```html
<!-- टेक्स्ट के लिए -->
<h1 data-translate="welcome_message">स्वागत संदेश</h1>

<!-- इनपुट प्लेसहोल्डर के लिए -->
<input type="text" data-translate="name_placeholder" placeholder="नाम दर्ज करें">
```

#### 3. नए अनुवाद जोड़ना:
```javascript
// language-switcher.js में
translations.hi['new_key'] = 'हिंदी अनुवाद';
translations.en['new_key'] = 'English translation';
```

## 🔧 तकनीकी विवरण (Technical Details)

### क्लास स्ट्रक्चर:
```javascript
class LanguageSwitcher {
    constructor() {
        this.currentLanguage = 'hi'; // डिफ़ॉल्ट: हिंदी
        this.translations = {
            hi: { /* हिंदी अनुवाद */ },
            en: { /* अंग्रेज़ी अनुवाद */ }
        };
    }
    
    // मुख्य मेथड्स
    switchLanguage(lang)     // भाषा बदलने के लिए
    getText(key)            // अनुवाद प्राप्त करने के लिए
    translatePageContent()   // पेज को अनुवादित करने के लिए
}
```

### डेटा एट्रिब्यूट्स:
- `data-translate="key"`: अनुवाद योग्य तत्वों के लिए
- `lang="hi"` या `lang="en"`: HTML lang एट्रिब्यूट

### लोकल स्टोरेज:
- `language`: वर्तमान भाषा ('hi' या 'en')

## 🐛 समस्याएं और समाधान (Troubleshooting)

### समस्या: भाषा स्विचर दिखाई नहीं दे रहा
**समाधान:** सुनिश्चित करें कि `language-switcher.js` स्क्रिप्ट लोड हो रही है

### समस्या: अनुवाद काम नहीं कर रहे
**समाधान:** `data-translate` एट्रिब्यूट जांचें और अनुवाद कीज़ सही हैं या नहीं

### समस्या: भाषा की पसंद सहेजी नहीं जा रही
**समाधान:** localStorage की अनुमति जांचें और ब्राउज़र कुकीज़ सक्षम हैं या नहीं
