# OverXchange

## Problem Statement

“In India, street food vendors have a problem with bringing in raw materials from trusted and cheap vendors.”

This project aims to explore the ecosystem of street food vendors, understand their pain points in sourcing raw materials, and build a web-based digital solution to address a specific angle of this issue.
